03Projects

Project 01 / 個人開発・試作品

勤務表作成支援ツール

Excelに入力した職員情報と勤務希望から、休日数・病棟の人数・職種・連続勤務を考慮した勤務表の下書きを作るPythonのツールです。

  • Python 3.14
  • OR-Tools（CP-SAT）
  • openpyxl
  • pytest
  • GitHub Actions

解決したい課題

希望休を1つ反映すると、別の日の人数や他の職員の連勤にも影響します。複数の条件を行き来しながら手作業で調整する負担を減らすことが目的です。

主な機能

  • 理由を付けて入力した希望・予定は変更せずに残す
  • 公休数と年休を合わせた必要休日数を、0.5日単位でちょうど割り当てる
  • 日曜日は各病棟ちょうど2名の出勤にする
  • 病棟の人数や役割の目安は「できるだけ満たす条件」として扱い、満たせなかった条件を表示する
  • 職員マスタと照合し、追加された職員の行をExcelに自動で追加する

実装の工夫

  • 勤務ルールを「必ず守る」「できるだけ満たす」「人が判断する」の3種類に整理してからコードにした
  • OR-Tools（CP-SAT）で、重要な条件ほど優先されるよう評価の重みを設計し、テストで確認した
  • openpyxlの行挿入では補正されない数式の参照・結合セル・入力規則を補正する処理を実装した
  • 一時ファイルに保存して再読み込みし、検証を通った場合だけ出力を置き換える（失敗時は前回の出力を残す）
  • 1つのファイルにまとまっていた処理を、読み込み・検証・最適化・出力などの役割別モジュールに分割した

テスト

pytestで99件（統合テスト2件を含む、2026年9月28日時点）。GitHub Actionsでpush時に自動実行しています。

条件と動作を検証するための試作品です。出力は担当者が確認・調整して使う前提で、現場での継続運用や時間削減の効果は検証していません。

GitHubでコードを見る READMEを読む
